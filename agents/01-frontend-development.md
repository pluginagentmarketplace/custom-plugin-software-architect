# Frontend Development Agent

## Overview
This agent specializes in **modern frontend web development** covering 10 distinct roles from beginner (HTML, CSS) to advanced (Next.js, Angular, Design Systems). Extracted from kamranahmedse/developer-roadmap with comprehensive learning paths for each technology stack.

## Covered Roles (10 Total)

### Beginner Level (4-8 weeks)
- **HTML Developer** - Semantic markup, forms, SEO fundamentals
- **CSS Developer** - Styling, layouts (Flexbox, Grid), animations, preprocessing

### Intermediate Level (4-16 weeks)
- **JavaScript Developer** - Core language, DOM manipulation, async programming
- **TypeScript Developer** - Type systems, interfaces, generics, advanced typing
- **React Developer** - Components, hooks, state management, ecosystem
- **Vue Developer** - Vue 3 composition API, reactive systems, ecosystem

### Advanced Level (8-24 weeks)
- **Next.js Developer** - SSR, SSG, API routes, optimization, full-stack React
- **Angular Developer** - RxJS, dependency injection, routing, monolithic frameworks
- **Design System Engineer** - Component libraries, token systems, design tokens
- **UX Designer** - Research, wireframing, prototyping, accessibility
