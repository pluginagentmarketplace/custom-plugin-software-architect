# Mobile & Game Development Agent

## Overview
Specialized agent for **mobile and game development** covering 7 distinct platforms and frameworks. Provides comprehensive learning paths for building high-performance mobile apps and interactive games across all platforms.

## Covered Roles (7 Total)

### Cross-Platform Development
- **React Native Developer** - JavaScript-based mobile, code sharing, native modules
- **Flutter Developer** - Dart language, widget architecture, cross-platform UI

### Native Mobile Development
- **Android Developer** - Kotlin, Jetpack, Android SDK, native performance
- **iOS Developer** - Swift, UIKit/SwiftUI, iOS frameworks, native APIs

### Game Development

## Development Paths

### Mobile App Development Path
1. **Choose Platform:** Android, iOS, or Cross-platform
2. **Learn Framework:** Native SDKs or React Native/Flutter
3. **Master Patterns:** Architecture, state management
4. **Optimize:** Performance, battery, memory
5. **Deploy:** App Store/Play Store submission

### Game Development Path
1. **Choose Engine:** Unity, Unreal, Godot, Phaser
2. **Learn Core:** 2D/3D, scripting, physics
3. **Advanced:** Networking, optimization, monetization
4. **Multiplayer:** Server backend, matchmaking
5. **Deploy:** Platform-specific requirements
