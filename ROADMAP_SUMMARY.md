## Quick Reference: Core Competencies by Role

### Computer Science
**Key Areas:** Fundamentals, Data Structures, Algorithms, Architecture & Design, Databases, Advanced Topics
**Duration:** 6-12 months
**Career Path:** Junior Dev → Senior Dev → Tech Lead → Architect

### Data Structures & Algorithms
**Key Areas:** Complexity Analysis, Linear Structures, Trees, Graphs, Sorting/Searching, Patterns, Advanced DS
**Duration:** 3-6 months
**Career Path:** Interview Prep → Algorithm Specialist → Competitive Programmer

### Git & GitHub
**Key Areas:** Basics, Branching, Advanced Operations, Collaboration, GitHub Features
**Duration:** 1-3 months
**Career Path:** All developers + DevOps specialization

### Technical Writer
**Core Competencies:**
- Fundamentals (research, structure, style)
- Documentation Types (API docs, guides, tutorials)
- Content Creation & Distribution
- Tools (Markdown, Git, API tools)

**Specializations:** API Doc Specialist, Developer Guide Writer, Technical Content Marketer
**Salary Range:** $50K-150K+

### Developer Relations
**Core Competencies:**
- Communication (speaking, blogging, writing)
- Community Building & Management
- Content Creation (blogs, videos, tutorials)
- Technical Knowledge (APIs, SDKs)
- Analytics & Metrics
- Soft Skills (listening, empathy, networking)

**Specializations:** Developer Advocate, Community Manager, Developer Evangelist, DevRel Manager
**Salary Range:** $80K-200K+

### QA Engineer
**Core Competencies:**
- Testing Fundamentals (20+ types)
- Performance & Load Testing
- Advanced Testing (accessibility, security, API)
- Testing Tools & Frameworks (30+ tools listed)
- Test Management & Automation
- Methodologies & Processes

**Specializations:** Automation Engineer, Performance Tester, Security Tester, Mobile QA, API Tester
**Salary Range:** $50K-180K+

### Engineering Manager
**Core Competencies:**
- Leadership & Vision
- People Management (hiring, feedback, development)
- Team & Project Management
- Technical Excellence (architecture, code review, tech debt)
- Organizational & Business
- Communication & Soft Skills

**Specializations:** Team Lead, Director, VP Engineering, CTO, Program Manager
**Salary Range:** $130K-400K+

### Rust
**Core Competencies:**
- Fundamentals (variables, functions, control flow)
- Ownership System (unique to Rust)
- Advanced Features (traits, generics, error handling, concurrency)
- Standard Library & Collections
- Ecosystem & Tools (Cargo, testing, documentation)
- Advanced Topics (async, unsafe, FFI)

**Specializations:** Systems Programming, Backend Web, Game Dev, Embedded, WASM, CLI Tools
**Key Tools:** Cargo, Tokio, Axum, Bevy, LLDB

### C++
**Core Competencies:**
- Basics (variables, control flow, pointers)
- Object-Oriented Programming
- STL (Standard Template Library)
- Templates & Metaprogramming
- Memory Management
- Modern C++ Features (C++11/14/17/20)
- Build Systems & Tools

**Specializations:** Systems Programming, Game Dev, HPC, Graphics, Embedded, Financial Systems
**Key Tools:** CMake, GCC/Clang, Unreal, Catch2
