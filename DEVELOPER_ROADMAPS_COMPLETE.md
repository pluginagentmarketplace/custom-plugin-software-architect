## Competency Levels

### Computer Science & DSA
- **Beginner:** Understand basic concepts
- **Intermediate:** Implement standard algorithms and data structures
- **Advanced:** Optimize for specific use cases, design custom structures

### Git/GitHub
- **Beginner:** Basic commit, push, pull, branches
- **Intermediate:** Rebase, merge strategies, pull requests, code review
- **Advanced:** Git internals, hooks, CI/CD integration, organizational workflow

### Rust
- **Beginner:** Variables, functions, basic ownership
- **Intermediate:** Traits, generics, error handling, async
- **Advanced:** Macros, unsafe code, performance optimization, systems programming

### C++
- **Beginner:** Basic syntax, OOP, STL containers
- **Intermediate:** Templates, smart pointers, modern C++ features
- **Advanced:** Metaprogramming, concurrency, optimization

### QA
- **Beginner:** Manual testing, basic automation
- **Intermediate:** Test frameworks, CI/CD, multiple testing types
- **Advanced:** Test architecture, performance testing, automation strategies

### Technical Writing
- **Beginner:** Basic documentation, tutorials
- **Intermediate:** API documentation, technical content marketing
- **Advanced:** Documentation strategy, content architecture

### DevRel
- **Beginner:** Community participation, technical blogging
- **Intermediate:** Speaking, event management, content creation
- **Advanced:** Community building, strategy, developer experience

### Engineering Management
- **Beginner:** Technical lead, small team
- **Intermediate:** Team lead, cross-functional projects
- **Advanced:** Multiple teams, organizational strategy, executive leadership

# CAREER PROGRESSION PATHS

## Technical Skills Progression

### Fundamentals (Months 1-6)
- Computer Science basics
- Git & GitHub workflows
- Data Structures & Algorithms
- Choose primary language (Rust or C++)

### Intermediate (Months 6-18)
- Choose specialization (QA, Technical Writing, DevRel)
- Deepen language expertise
- Build real projects
- Contribute to open source

### Advanced (Months 18-36)
- Expert-level specialization
- Technical leadership
- Mentoring others
- Architecture/Design decisions

### Senior/Leadership (36+ months)
- Team lead / Senior role
- Strategic decisions
- Cross-functional leadership
- Engineering manager track
