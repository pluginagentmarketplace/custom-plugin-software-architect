## Integration Examples

### Python
```python
import json

with open('frontend-roadmap.json', 'r') as f:
    roadmap = json.load(f)

# Access roles
for role in roadmap['roles']:
    print(f"{role['name']} - {role['difficulty']}")
    for category in role['skillCategories']:
        print(f"  {category['name']}: {len(category['skills'])} skills")
```

### JavaScript
```javascript
const fs = require('fs');
const roadmap = JSON.parse(fs.readFileSync('frontend-roadmap.json', 'utf8'));

roadmap.roles.forEach(role => {
  console.log(`${role.name} (${role.difficulty})`);
  console.log(`  Stages: ${role.learningPath.length}`);
  console.log(`  Technologies: ${role.keyTechnologies.length}`);
});
```

### SQL/Database
```sql
-- Import roles table
INSERT INTO roles (id, name, difficulty, estimatedTime)
SELECT 
  r.id, r.name, r.difficulty, r.estimatedTime
FROM frontend_roadmap_json r;

-- Create pivot for skill categories
INSERT INTO skill_categories (role_id, category_name, skills)
SELECT role_id, skillCategories->'name', skillCategories->'skills'
FROM roles;
```
