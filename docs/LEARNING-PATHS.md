## Fast Tracks (2-4 Months) ⚡

### Track 1: Prompt Engineering (FASTEST)

**Timeline:** 2-4 weeks

**Week 1-2: LLM Fundamentals**
- Understand what LLMs are
- ChatGPT, Claude, GPT-4 basics
- How to prompt effectively
- Difference between models

**Week 2-3: Prompt Engineering Techniques**
- Few-shot learning
- Chain-of-thought prompting
- Temperature and parameters
- Structured output

**Week 3-4: LLM Integration**
- API integration (OpenAI, Anthropic)
- Building simple applications
- Using prompt templates
- LLM model selection

**Agent:** 04-Data Science & AI
**Skill:** data-science/SKILL.md → Prompt Engineering section
**Projects:**
- Chatbot with custom instructions
- Content generator
- Code assistant

**Salary:** $80K-200K
**Market Demand:** 🔥 Highest
**Success Path:** AI Engineer (6-12 mo) → ML Engineer (18-24 mo)

## Standard Tracks (6-12 Months) 💼

### Track 1: Full-Stack Web Development

**Phase 1: Frontend Mastery (Weeks 1-12)**

- Week 1-2: HTML/CSS/JS fundamentals
- Week 3-4: TypeScript introduction
- Week 5-8: React deep dive
  - Hooks mastery
  - State management (Context/Zustand)
  - Component patterns
  - Performance optimization
- Week 9-12: Advanced frontend
  - Next.js basics (SSR)
  - Testing (Jest, Testing Library)
  - Design systems intro

**Phase 2: Backend Mastery (Weeks 13-24)**

- Week 13-14: Backend framework choice
- Week 15-18: Database & API design
  - SQL query optimization
  - API design best practices
  - Validation & error handling
- Week 19-22: Advanced backend
  - Authentication (JWT/OAuth)
  - Caching (Redis intro)
  - Deployment prep
- Week 23-24: Integration patterns

**Phase 3: DevOps Basics (Weeks 25-28)**

- Week 25: Docker containerization
- Week 26: CI/CD pipelines (GitHub Actions)
- Week 27-28: Cloud deployment (AWS/Heroku)

**Phase 4: Advanced Topics (Weeks 29-32)**

- Week 29: Performance optimization
- Week 30: Monitoring & logging
- Week 31: Scaling concepts
- Week 32: Career planning

**Agents:** 01-Frontend + 02-Backend + 05-DevOps
**Skills:** frontend, backend, infrastructure
**Portfolio Projects:**
1. Personal portfolio (weeks 1-6)
2. E-commerce site (weeks 13-28)
3. Real-time chat app (weeks 29-32)

**Salary Progression:**
- Junior: $70K-100K
- Mid-level: $100K-150K
- Senior: $150K-250K

**Next Steps:**
- Specialize in frontend (Design Systems)
- Specialize in backend (Microservices)
- DevOps specialization (SRE path)

## Success Criteria

### For Each Level

**Beginner→Intermediate:**
- ✅ Complete 5+ small projects
- ✅ Understand core concepts
- ✅ Build simple applications
- ✅ Read & understand code
- ✅ Ask good questions

**Intermediate→Advanced:**
- ✅ Complete 3+ medium projects
- ✅ Understand architecture
- ✅ Optimize for performance
- ✅ Write production code
- ✅ Review others' code

**Advanced→Expert:**
- ✅ Lead significant projects
- ✅ Mentor junior developers
- ✅ Make architectural decisions
- ✅ Contribute to open source
- ✅ Speak at conferences

## Recommended Study Patterns

### Time Commitment

| Pace | Hours/Week | Timeline (Standard Track) |
|------|-----------|--------------------------|
| Full-time | 40-50 | 6-9 months |
| Part-time intensive | 20-30 | 9-15 months |
| Part-time moderate | 10-15 | 15-24 months |
| Part-time light | 5-10 | 24-36+ months |

### Weekly Schedule

**Full-time:**
```
Mon-Thu: 10 hours coding + learning
Fri: 5 hours review + planning
Sat-Sun: 10 hours projects
Total: 50 hours/week
```

**Part-time intensive:**
```
Weekdays: 3 hours after work
Weekend: 8 hours
Total: 25 hours/week
```

**Part-time moderate:**
```
Weekdays: 1 hour evenings
Weekend: 3-4 hours
Total: 12 hours/week
```
