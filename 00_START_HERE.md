## Technology Stack Summary

### Programming Languages
- **Universal**: Python (required for all roles)
- **Data Roles**: Python + R + SQL
- **ML Roles**: Python + SQL + Java/Scala
- **Prompt Engineering**: Optional (conceptual)
- **Red Teaming**: Python + bash

### Machine Learning Stack
- **Classical ML**: Scikit-learn, XGBoost, LightGBM, CatBoost
- **Deep Learning**: TensorFlow, PyTorch, Keras, Jax
- **NLP**: Hugging Face, spaCy, NLTK
- **Computer Vision**: OpenCV, torchvision, TensorFlow Vision

### Data Infrastructure
- **Warehousing**: Snowflake, BigQuery, Redshift, Azure Synapse
- **Processing**: Apache Spark, Hadoop, Dask
- **Orchestration**: Apache Airflow, Prefect, Dagster, dbt
- **Streaming**: Kafka, Kinesis, Pub/Sub, Flink

### AI/LLM Tools
- **APIs**: OpenAI, Claude, Vertex AI, Cohere
- **Frameworks**: LangChain, LangGraph, CrewAI, AutoGen
- **Vector DBs**: Pinecone, Weaviate, Milvus, Chroma
- **RAG**: LlamaIndex, LangChain retrieval

### DevOps & Deployment
- **Containers**: Docker, Podman
- **Orchestration**: Kubernetes, Docker Compose
- **CI/CD**: GitHub Actions, GitLab CI, Jenkins, CircleCI
- **ML Platforms**: MLflow, SageMaker, Vertex AI, Kubeflow

### Visualization & BI
- **BI Tools**: Power BI, Tableau, Looker, Qlik
- **Python**: Matplotlib, Seaborn, Plotly, Dash
- **Web**: Streamlit, Gradio, Panel
