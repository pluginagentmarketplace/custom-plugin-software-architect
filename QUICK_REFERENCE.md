- ES6+, DOM API, Fetch API, Web APIs, npm/yarn, Webpack/Vite, Jest

### TypeScript Developer
- TypeScript, Generics, Decorators, Type System, Declaration Files

### React Developer
- React, JSX, Hooks, Redux, Router, Testing Library, Vite

### Next.js Developer
- Next.js, Server Components, API Routes, NextAuth.js, Prisma, Vercel

### Vue Developer
- Vue 3, Composition API, Pinia, Router, Vite, Vitest

### Angular Developer
- Angular, RxJS, Dependency Injection, TypeScript, Karma, Jasmine

### Design System Engineer
- Figma, Storybook, Component Libraries, CSS Architecture, npm

### UX Designer
- Figma, User Research, Wireframing, Prototyping, Analytics

## Learning Progression Path

```
BEGINNER (Week 0-8)
├─ HTML Developer (2-4w)
└─ CSS Developer (4-8w)
    ↓
INTERMEDIATE (Week 8-24)
├─ JavaScript Developer (6-12w)
├─ TypeScript Developer (4-8w) [after JavaScript]
├─ React Developer (8-16w) [after JavaScript/TypeScript]
├─ Vue Developer (8-12w) [after JavaScript/TypeScript]
│
└─ Design System Engineer (12-20w) [after CSS mastery]
    ↓
ADVANCED (Week 24+)
├─ Next.js Developer (8-16w) [after React]
├─ Angular Developer (12-20w) [after TypeScript]
├─ Design System Engineer (12-20w) [advanced systems]
└─ UX Designer (16-24w) [advanced research]
```
